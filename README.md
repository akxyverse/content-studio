## 🧭 About

Learning in public only works if the "public" part actually happens — this repository is where every post, article, tutorial, and visual asset gets drafted, stored, and organized before it goes out to LinkedIn, GitHub, or anywhere else.

## 💡 Why This Repository Exists

- 📣 **Content needs a production pipeline, not a scattered Drafts folder.** Ideas, drafts, and finished pieces each get their own stage here.
- 🎨 **Visual assets belong with the words they support.** Banners, thumbnails, and images live next to the content that uses them.
- 🔁 **It closes the loop on the rest of the ecosystem.** Projects, learning milestones, and certifications from elsewhere in this ecosystem become the raw material for what gets written here.

## 👥 Who This Is For

| | |
|---|---|
| ✍️ | Me, planning and drafting content before it's published externally |
| 👀 | Anyone following my content who wants to see the ideas pipeline behind it |
| 🎓 | Other content creators looking for a structure to organize their own output |

## ✨ Key Features

- 🗂️ **10 focused categories** — from raw ideas to finished, published-ready pieces
- 🎨 **Visual assets kept alongside written content** — Images, Banners, and Thumbnails have their own homes
- 🔄 **Built for a repeatable pipeline** — [`Content Ideas`](<./Content Ideas>) → drafts → [`Content Templates`](<./Content Templates>) → published

## 🗂 Repository Architecture

```
content-studio
│
├── LinkedIn Posts          # Drafts and published LinkedIn content
├── GitHub Content          # Content built for GitHub (profile README, repo write-ups)
├── Articles                # Long-form articles
├── Blogs                   # Blog posts written
├── Tutorials                # Tutorials created for others
├── Images                   # Supporting images
├── Banners                  # Banner graphics
├── Thumbnails                # Thumbnail graphics
├── Content Templates          # Reusable content templates
└── Content Ideas               # Backlog of content ideas
```

## 🚀 How to Use This Repository

1. **Got an idea?** It starts in [`Content Ideas`](<./Content Ideas>) before anything gets drafted.
2. **Writing something?** Pick the format — [`Articles`](./Articles), [`Blogs`](./Blogs), [`LinkedIn Posts`](<./LinkedIn Posts>), or [`Tutorials`](./Tutorials) — and use [`Content Templates`](<./Content Templates>) as a starting structure.
3. **Need visuals?** [`Banners`](./Banners), [`Thumbnails`](./Thumbnails), and [`Images`](./Images) hold the supporting graphics, built with the same visual language as this ecosystem's repo banners.

## 📐 Repository Rules & Conventions

- 🔒 **Structure is frozen** — no renaming, deleting, or restructuring the 10 categories.
- 🎨 **Visual assets follow the ecosystem's brand** — consistent typography, colors, and layout across every graphic produced here.
- 📝 **Ideas before drafts, drafts before publishing** — the pipeline stays linear, not chaotic.

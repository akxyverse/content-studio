# HR Dashboard — Microsoft Excel

**Published:** 2026-08-03 · **Platform:** LinkedIn · **Tool:** Microsoft Excel

An interactive HR dashboard built to turn raw employee salary data into
decision-ready insights — department payroll, city-wise headcount, salary
range, and highest/lowest earners — filterable through slicers instead of
manual spreadsheet filtering.
